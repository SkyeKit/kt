## 2. 各主题关键实现

### 2.1 多段伤害牌（hits）
- **根因**：伤害牌描述为"造成 X 点伤害两次"但 `cards.json` 缺 `hits`，`effectEngine` 用 `hits` 循环只跑一次。
- `parse-utils.mjs` 的 `parseEffects` 新增匹配 `(?:造成)?(\d+)点伤害[×x]?([0-9两二三四五六七八九十]+)[次段]`，`numToAr` 转中文数字；`effect.ts` 的 `damage` 效果支持 `hits`。
- `cards.json` 为 `twin_strike / fight_me / pummel / bite` 等补 `hits: 2`（`upgradeEffects` 同）。
- **注意**：重跑 `src/scripts/generate.mjs` 会覆盖手工精修的复杂卡效果（`chain_punch / body_slam`），务必从 Git 恢复后再补全。

### 2.2 随机卡居中展示（CardReveal）
- 目标：事件/遗物获得**随机卡**时直接居中显示，1s 后浮层消失，不弹选卡界面。
- `gameStore` 新增 `revealedCards: ref<Card[] | null>` + `revealCards(cards)`（1s 定时清空）。
- **共用入口统一展示**：`addDeckCard` / `addRandomFromPool` / `addCard` 加入牌组时即 `revealCards`。
- 遗物随机卡改造（选卡→随机+展示）：奥术卷轴、沉重石板、卷轴箱、寻龙尺、铅制镇纸、宾邦、涅奥的苦痛等。
- **踩坑**："沉重石板"因 `addDeckCard` 内部已 `revealCards`，随后手动展示被再入组覆盖 → 最终只有"受伤"无稀有牌。修复：先全入组，最后统一 `revealCards([受伤, 稀有])`；顺带清理残留 `console.error` DEBUG。
- 组件：[CardReveal.vue](file:///d:/muyu/kt/kt/src/components/common/CardReveal.vue)（`Transition` 淡入上浮、`pointer-events:none` 不挡交互），挂载于 `RunView.vue`。

### 2.3 商店 UI（多轮迭代，最终形态）
- 背景扩大（820→1400px，`max-width:96vw` 自适应，高 78vh）。
- **最终布局**：上排 6 张战士卡（满宽）；下排左侧无色卡(2张) + 右侧遗物(3件) + 删卡按钮，`justify-content:center` 整体居中，无右侧留空。
- **删除四个类型标题**："卡牌/无色卡/遗物/删除卡牌" 的 `<h3>` 全部移除。
- **特价卡机制**（每次进店 1 张战士卡 5 折）：
  - `setupShop` 随机选 1 张战士卡，`shopState.cards[].originalPrice` 记原价、`price = Math.ceil(原价/2)`。
  - UI：折后价绿色（+`class="sale"`），原价右侧灰字删除线 `text-decoration:line-through`；非特价卡只显单价。
- **药水预留槽已删除**（`potion-reserve` 及其样式移除）。
- 删卡按钮最终作为下排"无色卡+遗物+删卡"的一个区块，不再单独放右侧。
- **极重要：删卡点击必须绑 `CardView` 的 `@select` 事件**，而非容器 `@click`（CardView 自带 `@click.stop` 拦截冒泡）。

## 6. 关键经验教训（本轮沉淀）

- **UI"位置"需求必须先确认是哪个元素**：用户多次纠正"牌堆位置"——我第一次理解成按钮居中（错），实际是"点开牌堆后的查看界面"要像卡组一样居中。不确定是"按钮"还是"弹页"时应追问或做可逆小改动。
- **flex 全屏居中在内容超高时会裁切/偏左**：`justify-content:center`（column）加内容超高会从顶部裁掉、滚动不了、显偏左。改为 `inset:0 + justify-content:center + align-items:stretch` + 内部网格滚动（面板 `height:100%`），顶部留 `padding-top`。
- **数据源 md 与运行时 json 需双改**：改 `document/Overgrowth.md` 后必须同步适配 `src/data/enemies.json`（本类脚本非全自动，组合"或"需拆为独立数组项）。
- **共用入口二次展示会覆盖**：`addDeckCard` 内部已 `revealCards`，外层再调会再入组覆盖 → 先全部入组、统一展示一次。
- **开局自动触发节点要置 `visited`**：走 store 直接发（不点节点）时需手动把节点置为已访问，否则返回地图可再点。
- **地图滚动定位需等渲染安定**：`watch` 后 `nextTick` + `requestAnimationFrame` 再 `scrollIntoView`，否则因 flex/动画未稳定而回到顶端。
