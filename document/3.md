## 2. 各主题关键实现

### 2.1 控制台可视化浏览（第一阶段）
- 目标：在暂停菜单内用卡片网格替代命令输入，直观查看/操作卡牌与遗物。
- 顶部三标签页切换：**卡组卡牌 / 全部卡牌 / 全部遗物**；卡组卡牌用 `CardView` 逐张渲染，含"升级+"标记与序号角标。
- 全部卡牌按池分组（`cardGroups` 六类）：战士 / 无色 / 事件 / 衍生 / 状态 / 诅咒。
- 全部遗物遍历 `relicMap`，通过 `ownedRelics`（`Set(run.relics)`）标记"✓ 已拥有 / 未拥有"。
- **交互**：
  - 卡组卡：左键 → 详情浮层；右键 → 菜单「升级（+）/ 删除」（永恒牌删除禁用、已升级卡升级禁用）。
  - 全部卡：左键 → 详情；右键 →「加入牌组」。
  - 遗物：左键 → 详情（名称/稀有度/所属池/描述）；右键 → 未拥有「获得（触发拾起效果）」、已拥有「移除」。
- **实现要点**：详情浮层与右键菜单均用 `Teleport to="body"` 挂到根节点，避免被暂停面板裁剪；可交互格子补 `role="button"` + `tabindex="-1"`，确保无障碍树识别为独立点击节点（否则卡片内嵌 `CardView` 的 `@click.stop` 会拦截冒泡）。
- 遗物"获得"复用 store 的 `addRelicPickup`（先 `r.relics.push` 入库再由 store 触发 `ON_PICKUP`，与调试 `relic` 命令口径一致）。

### 2.2 左侧导航 + 右上搜索（第二阶段重构）
- **删除原命令区**：移除 `run()` 调度、`input`/`output` 状态、命令输出滚动区和快捷按钮（作弊命令不再保留，视觉浏览取代）。
- **左侧分类导航**（自上而下，展开式）：
  - 卡组
  - 卡牌（可展开/收起，`cardsOpen`）→ 子分类：角色·基础 / 角色·普通 / 角色·罕见 / 角色·稀有 / 无色卡 / 状态卡 / 诅咒卡 / 事件卡 / 衍生卡
  - 遗物
- 导航状态用 Union 类型 `NavState = {kind:'deck'} | {kind:'cards';pool;rarity?} | {kind:'relics'}`；右侧内容依 `nav.kind` 分支渲染。
- **右上角搜索框**：`searching` 为真时内容区改为展示搜索结果（卡牌块 + 遗物块），按「名称 / id」不区分大小写做 `includes` 模糊匹配，复用 `cardMap` 全池与 `relicMap`；搜索结果同样支持左键详情、右键加入牌组/获得。
- **踩坑（TS 类型，已在后文记录）**：Union 态窄化访问 `nav.value.rarity` 时 TS 推断失效，须先赋值局部变量 `const cur = nav.value` 再取值。

### 2.3 分类与遗物菜单微调
- 移除 `cardSubNavs` 中的"角色·基础"项 → 角色卡仅保留：角色·普通 / 角色·罕见 / 角色·稀有。
- 遗物右键菜单收敛为**只有「获得（触发拾起效果）」一项**；已拥有者该项置灰并改文案为「已拥有」，防止重复入库（不再提供"移除"）。

### 2.4 暂停菜单重打直接返回
- `PauseMenu.vue` 的 `retry()`：`restartNode()` 成功 → 先 `goByPhase()` 切到战斗/地图 → 再 `emit('close')` 关闭菜单覆盖层，直接进入当前场景，不再停留暂停菜单；无快照时照旧退化为仅关闭。

## 6. 关键经验教训（本轮沉淀）

- **卡片独立点击性**：卡格里 `CardView` 自带 `@click.stop`，直接绑容器 `@click` 会丢失焦点。需给格子加 `role="button" + tabindex="-1"` 并绑 `@click.stop` 绑定层，确保事件/无障碍可命中。
- **浮层裁剪**：缩放详情浮层与右键菜单要 `Teleport to="body"`，否则被暂停面板的 `overflow`/`max-height` 裁掉。
- **TS Union 态窄化失效**：`nav.value` 在 `if (nav.value.kind !== 'cards') return` 后，链式 `nav.value.rarity` 仍报错。先把窄化结果赋给局部 `const cur = nav.value` 再访问可选字段即解决。
- **已删除逻辑需同步清理**：删除命令区时，连带把不再用到的 `push/findCard/quickCards/run` 一并移除，避免 lint 报未使用变量。
- 每次改动后固定跑 `pnpm typecheck && pnpm lint`；本会话改动纯 UI 组件，未触及引擎，测试集保持 180 全绿。
