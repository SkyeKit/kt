## 1. 地图介绍

**巢穴（Hive）** 是《杀戮尖塔2》的**第二阶段**场景，整体设计风格以**各类虫类生物**为主题。

### 1.1 阶段结构（共 16 层，第 18~33 层）

| 楼层     | 固定内容                                               |
| -------- | ------------------------------------------------------ |
| 第 18 层 | **先古之民**（击败上一阶段 Boss 后迎接，给予独特遗物） |
| 第 19 层 | 必定为一场**普通怪物**战斗                             |
| 第 26 层 | 必定为**宝箱房**                                       |
| 第 32 层 | 必定为**休息处**（篝火）                               |
| 第 33 层 | **Boss 战**                                            |

### 1.2 遭遇战机制

- 战斗遭遇分为**普通战斗、精英战斗、首领战斗**三类。
- 普通战斗：**前 2 场**从弱怪池抽取，**第 3 场及以后**从强怪池抽取。
- **佩尔、欧洛巴斯、特兹卡塔拉**只会在第二阶段出现。
