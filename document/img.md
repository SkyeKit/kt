# 美术资源占位与命名说明清单（img.md）

> 本清单由 `document/` 目录下的游戏源数据文件**逐项解析**生成，作为后续接入 UI 图片的占位与命名依据。
> **排除文件**（规范/说明类，不产生美术资源）：`ui.md`、`agent.md`、`event.md`、`PRD_v1.0.md`。
> **命名规则**：
>
> - 怪物：`assets/enemies/<幕>/<english_id>.png（<中文名>）`，`<english_id>` 取地图文件括号内英文名的 snake_case。
> - 遗物：`assets/relics/<遗物池>/<中文名>.png（<中文名>·<稀有度>）`；`relic.md` 仅含中文名，代码级 snake_case id 在生成 `data/relics.json` 时再映射。
> - 其余资源按 PRD §5.4 / agent.md §9 的约定。

## 三、命名与接入约定

- **怪物 id**：取自各地图文件怪物详情标题括号内的英文名（如 `毛绒伏地虫（Fuzzy Wurm Crawler）` → `fuzzy_wurm_crawler`）。每个怪物目录下含 `idle.png` / `portrait.png` / `atk_sheet.png`（横向帧条，见 PRD §5.4.8）。
- **遗物 id**：`relic.md` 仅有中文名，此处以中文名作为占位文件名；生成 `data/relics.json` 时统一映射为 snake_case id（如 `燃烧之血` → `burning_blood`），组件按 `icon` 字段引用，不硬编码。
- **来源可追溯**：每个占位对应 `document/` 下某一源文件，美术替换时保持同名即可。
- **缺失处理**：任意资源缺位时组件降级为纯色块 + 文字/首字，保证无图也能跑通。
- **数量统计**：遗物共 298 个（跨 15 个池）；怪物共 72 个（跨 4 幕）。
