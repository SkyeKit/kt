# 杀戮尖塔2 · 附魔数据总览（enchantments.md）

> 数据来源：slaythespire2.gg（`/zh/enchantments`），对应游戏版本 v0.107.1。
> 附魔是《杀戮尖塔 2》中贯穿整局运行的卡牌强化系统。一旦通过事件、遗物或商店施加到某张卡牌上，
> 该附魔会跟随这张卡牌的特定副本持续到本局结束（绑定单张卡牌副本）。

---

## 一、附魔核心规则

| 规则 | 说明 |
| ---- | ---- |
| 绑定单张卡牌副本 | 附魔一旦施加，仅跟随该副本，持续整局。 |
| 每张卡牌一个附魔 | 大多数卡牌同一时间只能拥有一个附魔；叠加极为罕见且受限。 |
| 在卡牌文本中预览 | 每个附魔有独立图标和额外规则文本，会随卡牌数值动态更新。 |
| 完全可选 | 提供附魔的事件和遗物通常给你选择权，常以 HP、金币或诅咒为代价。 |

## 三、附魔类型（按玩法角色）

### 伤害成长

| 附魔 | 规则 |
| ---- | ---- |
| 锋利 | 这张牌上的伤害值固定 +3。 |
| 动量 | 本场战斗每次打出该牌，其攻击伤害 +5（战斗中累计）。 |
| 活力 | 首次打出该牌时，造成 8 点额外伤害。 |
| 腐化 | 造成的伤害 +50%（乘算），但每次打出失去 2 生命。 |
| 本能 | 这张牌的攻击伤害翻倍（×2）。 |

### 格挡与防御

| 附魔 | 规则 |
| ---- | ---- |
| 伶俐 | 打出时获得 3 点格挡。 |
| 灵巧 | 该牌获得的格挡 +2。 |
| 黏糊 | 该牌获得消耗；每次打出时其格挡值永久 +1。 |

### 抽牌与节奏

| 附魔 | 规则 |
| ---- | ---- |
| 迅速 | 首次打出该牌时抽 1 张牌。 |
| 播种 | 每场战斗首次打出该牌时获得 1 点能量。 |
| 墨影 | 打出时施加 1 层虚弱。 |

### 关键词与行为改变

| 附魔 | 规则 |
| ---- | ---- |

### 附魔的来源

大多数附魔由后期遗物和事件奖励，而非普通卡牌奖励。提及「附魔一张卡」的事件链通常让你从牌组中选一张卡，
然后施加上述附魔之一。若干稀有遗物在拾取时也会为打击、防御或选定的一组攻击/技能附魔。

### 何时选择（或跳过）附魔

由于附魔是永久的且常伴随代价（HP 损失、金币、诅咒或牌组扭曲），最佳时机是当你有一张明确的「核心卡」定义牌组时。
成长型附魔适合你计划每场战斗多次打出的卡，而保留/重放型附魔适合高影响、高费用的终结技。
若事件提供附魔但你尚无真正受益的卡，通常应跳过并保留 HP 或金币以待后续机会。

## 五、引擎实现约定（agent.md §5.1 数据驱动）

- 附魔数据独立存于 `src/data/enchantments.json`（由 `scripts/parse-enchantments.mjs` 从本文件生成），引擎/组件禁止硬编码。
- 卡牌运行时字段 `Card.enchantments?: string[]` 挂载附魔 id 数组（与 `Card.upgrade` 同为"作用于该 id 全部副本"的 MVP 简化）。
- 战斗内按附魔语义叠加效果：伤害/格挡加成在 `combatEngine.playCard` 结算时并入；首次触发（迅速/播种/活力）、
  战斗中累计（动量）、每场一次（华彩）等经 `ctx.enchantState`（按卡 id 记录）跟踪。
- 附魔词条缺失引擎支持时，效果降级为仅 UI 提示（与未实现子系统惯例一致）。

### 语义字段字典

| 字段 | 类型 | 含义（引擎如何应用） |
| ---- | ---- | -------------------- |
| damage | number | 打出时固定伤害加成（锋利 +3、特兹卡塔拉的余烬 +3） |
| damageMult | number | 打出时伤害倍率（腐化 ×1.5、本能 ×2；与易伤/虚弱同一结算链） |
| firstPlayDamage | number | 每场战斗首次打出时额外伤害（活力 8） |
| momentumPerPlay | number | 本场战斗每次打出伤害累计 +N（动量 5，战斗内累加） |
| blockBonus | number | 打出时格挡加成（伶俐 +3、灵巧 +2） |
| goopyBlock | boolean | 打出时该牌格挡值永久 +1（黏糊，MVP 作用于该 id 全部副本） |
| applyWeak | number | 打出时施加虚弱层数（墨影 1） |
| loseHp | number | 打出时失去生命（腐化 2） |
| exhaust | boolean | 该牌获得消耗关键词（黏糊） |
| removeExhaust | boolean | 该牌移除消耗关键词（灵魂之力） |
| innate | boolean | 该牌获得固有（王室认证） |
| retain | boolean | 该牌获得保留（王室认证、稳定） |
| costZero | boolean | 该牌费用变为 0（特兹卡塔拉的余烬） |
| unique | boolean | 该牌获得永恒（特兹卡塔拉的余烬） |
| replayOnce | boolean | 每场战斗可重放一次（华彩） |
| replay1 | boolean | 该牌获得 1 层重放（涡旋） |
| autoPlayAtStart | boolean | 战斗开始时自动打出（注能） |
| topOfDrawPile | boolean | 洗入抽牌堆时放抽牌堆顶（完美契合） |
| randomizeCost | boolean | 抽到时费用 0~3 随机（蛇行） |
| reduceCostInHand | boolean | 回合结束若在手牌费用 -1，直到打出（沉眠精华） |
| firstPlayDraw | number | 每场首次打出抽牌数（迅速 1） |
| firstPlayEnergy | number | 每场首次打出获得能量（播种 1） |
| cloneAtRest | boolean | 可在休息处复制该牌（克隆） |
