## 1. 地图介绍

**荣耀（Glory）** 是《杀戮尖塔2》的**第三阶段**场景，整体设计风格以**各类偏西式的古典奇幻形象**为主题，并有大量人形敌人。

### 1.1 阶段结构（共 15 层，第 34~48 层）

| 楼层     | 固定内容                                               |
| -------- | ------------------------------------------------------ |
| 第 34 层 | **先古之民**（击败上一阶段 Boss 后迎接，给予独特遗物） |
| 第 35 层 | 必定为一场**普通怪物**战斗                             |
| 第 41 层 | 必定为**宝箱房**                                       |
| 第 47 层 | 必定为**休息处**（篝火）                               |
| 第 48 层 | **Boss 战**                                            |

### 1.2 遭遇战机制

- 战斗遭遇分为**普通战斗、精英战斗、首领战斗**三类。
- 普通战斗：**前 2 场**从弱怪池抽取，**第 3 场及以后**从强怪池抽取。
- **坦克斯、瓦库、诺奴佩普**只会在第三阶段出现。
