## 1. 地图介绍

**暗港（Underdocks）** 是《杀戮尖塔2》的**第一阶段**场景之一，整体设计风格以**海洋或水生动物**为主题。

### 1.1 阶段结构（共 17 层）

| 楼层     | 固定内容                                                      |
| -------- | ------------------------------------------------------------- |
| 第 1 层  | **先古之民**（从第二局游戏开始，玩家会在此迎接**涅奥** Neow） |
| 第 2 层  | 必定为一场**普通怪物**战斗                                    |
| 第 10 层 | 必定为**宝箱房**                                              |
| 第 16 层 | 必定为**休息处**（篝火）                                      |
| 第 17 层 | **Boss 战**                                                   |

### 1.2 遭遇战机制

- 战斗遭遇分为**普通战斗、精英战斗、首领战斗**三类。
- 普通战斗：**前 3 场**从弱怪池抽取，**第 4 场及以后**从强怪池抽取。
- 与密林相同，暗港的**强怪池和精英池相比前作均得到大幅度加强**。
